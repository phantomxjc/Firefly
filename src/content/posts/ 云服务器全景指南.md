> 做个人项目、搭个小站、跑个脚本，谁都想白嫖一台服务器。但"免费"二字水很深：有的真永久、有的限时试用、有的只免部分服务、有的干脆要你发帖拉人。本文把国内外主流免费主机按"真免费程度"分门别类，讲清各自能跑什么、坑在哪里，帮你少走弯路。

---

## **一、先分清"免费"的几种形态**

在动手注册之前，先认清你拿到的是哪种"免费"，避免用完才发现要掏钱：

1. **真·永久免费虚拟机**：能 SSH 登录的完整虚拟机，无使用期限。全球范围内极稀缺。
2. **额度内免费**：每月送一点额度或资源，轻量应用常驻免费，超过才计费。接近永久，但有上限。
3. **永久免费但非虚拟机**：无服务器 / 边缘计算平台，跑网站、API 足够，但不能装任意操作系统、不能跑长驻进程。
4. **限时试用**：新用户送额度或 12 个月免费套餐，是厂商的"拉新体验"，到期自动转付费。
5. **国内专属**：受成本与合规影响，基本只有短期试用和学生机，没有永久免费虚拟机。

## **二、海外免费主机**

### **2.1 真·永久免费虚拟机（最稀缺）**

**Google Cloud（GCP）e2-micro —— 最推荐**

- 配置：1 个 e2-micro 实例（约 0.25~2 个共享 vCPU）+ 1 GB 内存 + 30 GB 标准持久磁盘。
- 区域限制：必须建在指定美区（`us-west1` / `us-central1` / `us-east1`），建错区域会真实扣费。
- 流量：含每月一定的免费出站流量额度（具体数字以官方文档为准，建议搭配预算告警）。
- 需要信用卡验证；实例有公网 IP，可安装任意 Linux 发行版。
- 优点：大厂稳定、真永久、灵活。
- 缺点：美区节点国内访问延迟高；共享 vCPU 性能有限，跑重负载会被限频。

> 参照项：Oracle Cloud Always Free 是最慷慨的（2 台 AMD + 4 核 ARM 永久免费），但注册常需拼运气、容易名额紧张，本文将其作为"免费天花板"参照，不作重点展开。

### **2.2 额度内免费（接近永久，轻量够用）**

**[Fly.io](http://Fly.io) —— 低延迟小虚拟机的首选**

- 每月 **$5 免费额度**（按组织计算），可部署 Docker 容器，分配公网 IP，支持 `fly ssh console` 登录，体验最接近完整虚拟机。
- 256 MB 共享 CPU 的虚拟机约 $1.9/月，三台可常驻在免费额度内。
- 节点覆盖多区域（含新加坡、香港），延迟比 GCP 美区友好。
- 需要信用卡；超出 $5 会计费，IPv4 可能单独收费，需注意。

**Render / Railway / Koyeb**

- 提供免费 Web Service / 容器，带休眠机制或额度限制。
- 适合网站后端、API 服务，多为应用托管而非纯虚拟机。

### **2.3 永久免费但非虚拟机（无服务器 / 边缘，功能强、国内快）**

**Cloudflare 全家桶 —— 功能最丰富、免信用卡、国内访问快**

- Workers：每天 10 万请求免费。
- Pages：静态站点托管 + 每月 500 次构建，带宽近乎无限。
- R2：10 GB 对象存储免费。
- D1：SQLite 数据库免费额度；另有 KV、Durable Objects 等。
- 支持 JavaScript / TypeScript；也支持 Python（基于 Pyodide，只能用纯 Python 包，无法使用需要 C 扩展的库）；**原生不支持 PHP 运行时**。
- 优点：无需信用卡、全球 CDN 加速、国内打开快、稳。
- 缺点：不是完整虚拟机，不能装任意系统、不能跑需要长驻进程或特定端口的服务，不适合代理、爬虫、重计算类任务。

**Vercel / Netlify**

- 前端 + Serverless Function 免费档，适合静态站和前端项目。

### **2.4 限时试用（大厂拉新，练手很爽）**


| **厂商** | **免费内容** | **有效期** | **需信用卡** |
| ------------ | ----------------------------------------- | ---------------------- | -------- |
| AWS | 12 个月免费套餐（t2/t3.micro 等指定机型）+ 部分服务永久免费层 | 12 个月 | 是 |
| Azure | $200 试用额度 + 12 个月免费服务（B1S 等）+ 55+ 项始终免费服务 | $200 用 30 天；免费服务 12 个月 | 是 |
| Google Cloud | $300 试用额度（另有 e2-micro 永久档，见 2.1） | 90 天 | 是 |

> 注意：这些都是"拉新体验"性质，一个身份通常只能领一次；到期或超额会**自动转付费扣款**，务必设置预算告警、不用及时删除资源。

## **三、国内免费主机现状**

结论先说：**国内没有永久免费的云服务器（虚拟机）**。主流厂商情况如下：

- **阿里云 / 腾讯云 / 华为云 / 火山引擎 / 京东云** 等：只有新人 1~3 个月试用机、低至几元的体验机；通过学生认证后有"学生机"约 ¥10/月（并非免费）；以及不定期的开发者扶持活动机。
- 想要"国内节点永久免费虚拟机"基本不存在（成本与合规原因）。
- 折中方案：用 **Cloudflare 做前端**（国内访问快、永久免费）+ **海外免费虚拟机做后端**，兼顾速度与零成本。

## **五、避坑指南**

- **"永久免费"不等于"白嫖大机器"**：Oracle 的慷慨是特例，其余平台资源都很有限。
- **大多需要信用卡**：务必设置预算告警；GCP 选错区域、[Fly.io](http://Fly.io) 超额度都会真实扣费。
- **限时额度到期自动转付费**：AWS / Azure / DigitalOcean 的试用金用尽或到期即开始计费，不用及时删资源。
- **论坛"发帖送 VPS、邀请送机器"**：大多不靠谱，可能跑路或夹带后门，谨慎对待。
- **学生认证额度（GitHub Student Pack）**：含 DigitalOcean $200、Azure for Students $100/12 个月（免信用卡）等，需 .edu 或学生认证。

## **六、按用途选型**

- **想要真虚拟机、永久免费** → Google Cloud e2-micro（接受美区高延迟）。
- **想要低延迟小虚拟机** → [Fly.io](http://Fly.io)（额度内免费，亚太节点可选）。
- **只跑网站 / API / 静态站，想零成本且国内快** → Cloudflare 全家桶。
- **要跑重 Python、原生库（pandas / torch 等）或长任务** → [Fly.io](http://Fly.io)（Docker）或 GCP e2-micro 这类原生环境。
- **必须用 PHP（WordPress / Laravel 等）** → [Fly.io](http://Fly.io) / Render / Railway（Docker）或一台免费虚拟机自建 LAMP，Cloudflare 不适合。
- **想要国内节点** → 基本无永久免费，只能付费买轻量 / 学生机，或用"Cloudflare 前端 + 海外虚拟机后端"组合。
- **短期练手、尝鲜** → DigitalOcean $200/60 天、Azure $200/30 天 + 12 个月免费服务。

## **结语**

白嫖有道，选对平台能省下真金白银。看清"永久 / 额度 / 限时"的区别，避开信用卡自动扣费的坑，再把用途和节点要求对上号，你就能用近乎零的成本把项目跑起来。合规使用，快乐折腾。
