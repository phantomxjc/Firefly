你有没有过这种经历——想找个电影或者资料，到处群里问「有没有人存过」，发了一堆链接过去，点开不是失效就是需要会员。网盘资源这东西，**找起来像大海捞针，全靠运气**。

今天给兄弟们安利两个 Docker 组合工具，把「找资源」这件事彻底自动化。

## 第一个工具：Pansou

**Pansou**，作者在 GitHub 上叫 fish2018，一个用 Go 写的高性能网盘资源搜索服务，目前 **1.4 万 Star**，相当炸裂。

它干的活儿特别简单直接——给你搭一个网盘搜索引擎，支持搜索：

- 阿里云盘
- 百度网盘
- 夸克
- 迅雷
- 115
- PikPak 等等主流网盘

更厉害的是它**支持多频道并发搜索**，你搜一个关键词，它同时在多个 Telegram 频道和多个插件里查，然后把结果智能排序推给你。

Pansou 的架构很有意思，底层用的是 Telegram 频道的搜索结果加上各种搜索插件，前端是个清爽的搜索界面，Docker 一键部署，端口 8888，装完就能用。作者还集成了异步搜索和结果缓存，**搜过的东西不会重复跑**。

官方首页已经部署了演示站，地址是 `so.252035.xyz`，感兴趣的朋友可以先去感受一下搜索速度。

## 第二个工具：Quark-Auto-Save

光会搜还不够，你搜到一条夸克网盘链接，还得手动打开夸克 App，点转存，再整理名字，这一套下来够烦的。

**Quark-Auto-Save** 就是来解决这个问题的，作者 Cp0204，Python 写的，2994 Star，不算大但很实用。它的核心功能就四个字——**自动转存**。

- 把夸克分享链接喂给它，**自动帮你存到自己网盘里**
- 还能**自动按格式命名整理**，省去一堆手动操作
- 每天**自动签到领空间**
- 会发**推送通知**你最近哪些资源被转存了
- 甚至可以**联动媒体库自动刷新**

端口默认 5005，在 Docker 里映射成 15005 方便访问。

## 组合起来用

把这两个工具搭在一起，工作流是这样的：

> 用 Pansou 搜资源 → 找到夸克网盘链接 → 复制到 Quark-Auto-Save 的输入框 → 一键自动转存、自动命名、自动整理

从「到处求人」到「全自动搞定」，中间就隔着**两行 Docker Compose**。

部署方式很直接，一个 docker-compose.yml 搞定：

```yaml
services:
  pansou:
    image: ghcr.nju.edu.cn/fish2018/pansou:latest
    container_name: pansou
    restart: unless-stopped
    environment:
      - PORT=8888
      - CHANNELS=tgsearchers4,Aliyun_4K_Movies,bdbdndn11,yunpanx,bsbdbfjfjff,yp123pan
      - ENABLED_PLUGINS=labi,zhizhen,shandian,duoduo,muou,wanou,hunhepan,jikepan,pansearch
      - CACHE_ENABLED=true
      - CACHE_PATH=/app/cache
      - ASYNC_PLUGIN_ENABLED=true
    volumes:
      - ./pansou/cache:/app/cache
    network_mode: host

  quark-auto-save:
    image: ghcr.nju.edu.cn/cp0204/quark-auto-save:latest
    container_name: quark-auto-save
    restart: unless-stopped
    ports:
      - "15005:5005"
    volumes:
      - ./quark-auto-save/config:/app/config
      - ./quark-auto-save/media:/media
```

> **注意：** Pansou 用的是 host 网络模式，夸克自动转存映射到 15005 端口，分别挂载缓存目录和配置目录，整个配置下来不到 20 行。`CHANNELS` 和 `ENABLED_PLUGINS` 那两项可以按需增减，默认给的频道和插件组合已经覆盖了不少主流资源。

装完之后，浏览器打开 `localhost:8888` 就是 Pansou 的搜索界面，搜到资源复制夸克链接，打开 `localhost:15005` 把链接丢进去，剩下的事情交给这两个容器自己处理。
