# 1元用1年！这家美国VPS商把主机打成白菜价

> 1G空间+5个域名+PHP 8.4，比一瓶水还便宜

## 01 · 缘起

前两天在 TG 群里看到有人聊 MatrixIDC，说他们家出了个"免费虚拟主机"，一年只要 1 块钱。

第一反应是：又来一个钓鱼的。点进去一看，还真不是套路—— **1 块钱，确实真能买**。当然，免费主机这个行业的水，比太平洋还深。1 块钱能买什么、值不值买，今天就把这事掰开揉碎说清楚。

## 02 · 初见

MatrixIDC（矩阵 IDC），一家美国 VPS 商家，主业是洛杉矶、圣何塞机房的机器，主打"中美访问优化"。产品线挺全：CN2 GIA、三网 4837、中美直连、ISP 落地出口，看着不像那种打一枪换一个地方的野鸡商家。

官网写的运营主体是 **Matrix Node LLC**，注册在美国科罗拉多州，有正规的服务条款、AUP、退款政策，条款全部 2026 年 7 月更新过，措辞成熟，不是拿模板糊弄人的那种。

VPS 产品卖得不便宜（1C/1G 那档年付 240 元，2C/4G 年付 580），也不便宜得离谱——正常市场价。

**但今天要聊的不是 VPS，是他们的"免费虚拟主机"。**

## 03 · 实测

**先说配置：**

| | |
|---|---|
| 网站空间 | **1024 MB**（1G）|
| 数据库 | 1 个（官方写的是 0 MB 空间，建议找客服确认） |
| 可绑域名 | **5 个** |
| FTP 用户 | 5 个 |
| PHP 版本 | **8.2 / 8.3 / 8.4**（Nginx + PHP-FPM） |
| 邮件服务 | **不提供** |
| 价格 | **¥1.00 / 年**（≈¥0.08/月） |
| 库存 | 剩 92 台（写稿时数据） |

1 块钱，买不了吃亏。能跑什么？WordPress、Typecho、Hexo 这类博客绰绰有余；5 个绑域意味着你可以搭个个人导航、简历站、作品集站，全塞进去。

**几个需要注意的点：**

🔴 **没有邮件服务**。想跑需要发验证邮件的系统（注册确认、忘记密码），别想了，换别的方案。

🔴 **数据库写的是"0 MB"**。虽然给了 1 个数据库，但存储空间是 0，这配置有点迷。要么找客服确认，要么自己建个库试。

🔴 **免费产品没有 SLA**。官方服务条款写得很清楚：不承诺固定响应或恢复时长。机器挂了，1 块钱别想要赔偿。这是所有免费主机的通病，不能算鸡贼，但得心里有数。

🔴 **海外主体**。主机在美国，如果你的访客主要在国内，建议先建个小站测测速度再决定要不要搬上去。

**✦ 优点：** 1块钱用一年、5个域名、PHP 8.4、非野鸡商家（VPS 圈有真实测评、有活跃 TG 群、有正规退款政策）
**✦ 缺点：** 数据库表述含糊、无邮件、无 SLA、海外主机、免费产品稳定性不可控

## 04 · 闲话

写这篇的时候，顺手翻了翻第三方测评。有两家测过他们家的 VPS：晚高峰下行 800M-1Gbps，电信延迟 180ms、联通 170ms、移动 190ms，EPYC 7763 的 CPU，4K 随机读 800MB/s——数据说不上多亮眼，但在美西 VPS 里算合格水平。

**关键是：这些是 VPS 测评。** 免费虚拟主机和 VPS 是两套系统，VPS 的口碑不能直接平移到免费主机上。这篇文章只能算"信息搬运+主观分析"，目前还没有针对这款免费主机的独立实测，实际体验还得你自己动手试。好在价格是真便宜，试错成本极低。

**我的建议：**

- 学生党想练手部署 PHP → **冲**
- 想给作品集 / 简历 / Demo 找个地方放 → **合适**
- 博客想从免费平台迁出来，又不想花钱 → **可以试**
- 企业站 / 电商 / 挂了要赔钱的业务 → **别**
- 需要发邮件的 → **别**

这类"1元主机"本质上是商家获客用的引流产品，目的是让你体验爽了之后去开他家 28/38/58 一个月的 VPS。不过有句话说得好：**"我不在乎你打什么算盘，我只在乎我能不能薅到羊毛。"** 对这家来说，这个羊毛目前是薅得到的。
