C盘又红了？试了100种方法，最后被这个开源小工具救了

📅 2026-07-31

上周五下午三点，屏幕右下角弹出一条通知——「C盘空间不足」。

我机械地点开「设置 → 存储」，看着那个刺眼的红色条——256G的C盘只剩7个G，而我的D盘还有800多G空着。

那一刻的心情，怎么说呢……就像手机只剩1%电量，身上还没带充电宝。

接下来半小时，我陷入了「清理C盘」的经典循环：

⚠️ 打开磁盘清理 → 点了"清理系统文件" → 等了三分钟 → 告诉我能清2.3GB → 犹豫要不要删"Windows更新清理"→ 取消
打开临时文件夹 → 几千个tmp文件 → 手动选中 → 右键删除 → 部分文件被占用删不掉 → 放弃
打开微信设置 → 清理微信缓存 → 提示"清理后将无法查看历史图片" → 取消

每次都是鼓起勇气开始，灰溜溜地退出——不是不想清，是真不敢乱删。 Windows那些文件夹，哪个能删哪个不能删，鬼知道啊。

01后来我是怎么彻底解决这个问题的

在踩了无数坑之后，我开始认真研究C盘到底被什么吃掉了。

结果不看不知道，一看吓一跳——Windows系统里这些文件夹，每个都能轻松吃掉几十GB：

文件夹 / 文件类型
常见大小

%TEMP% / 临时文件
5~30 GB

Windows Update 缓存
3~20 GB

浏览器缓存（Chrome/Edge）
2~15 GB

微信 / QQ 聊天缓存
10~50 GB（重灾区）

回收站
1~10 GB（删了但没清空）

日志文件 / .old 备份
2~10 GB

休眠文件（hiberfil.sys）
= 内存大小（16G内存 = 16G）

加起来，轻轻松松三五十GB——怪不得C盘总是爆红。

手动一个个清理太麻烦，用那些XX管家、XX安全卫士又不放心——弹窗广告、全家桶捆绑、后台静默安装……本来想清理电脑，结果电脑被"清理"了。

02这个开源工具，解决了我所有的焦虑

GitHub 上有个叫 JIEKE66633 的开发者做了个小工具，叫「C盘清理工具」，刚更新到 v1.2.0，用了一次之后我把XX安全卫士彻底删了。

它最打动我的，是三个设计：

🔍
先预览，再动手
一键扫描C盘，把所有可清理项按类型列出来。开启「模拟模式」，能看到要删什么，但实际不删。真正动手前，心里有底。

🛡️
删错了也不怕
开启「备份模式」后，每次删除前自动备份，误删了可以一键恢复。这是我最需要的安全感。

⚡
精准清理，想删哪个删哪个
支持单选/全选/取消全选，右键文件项可以直接打开所在位置。不用一刀切，微信缓存想清就清，系统日志想留就留。

用了一次，扫出来14.7GB垃圾，模拟模式确认无误后一键清理，全程不到两分钟。

关键是——没有弹窗，没有广告，没有任何多余操作。 开源项目，就一个exe，解压即用，干净得像个异类。
