# 前两天才推荐的 GLM-5.2，今天就用不了了

写文章这事有个尴尬：你好不容易发现一个免费又好用的东西，兴冲冲推荐给读者，没过两天它就用不了了。

前两天我刚给大家推荐过智源的 GLM-5.2——通过 NVIDIA 的 API 站点（integrate.api.nvidia.com）就能白嫖，速度快、质量稳，写代码、总结文章都不在话下。结果昨天还有人在后台问"是不是你打开方式不对"，今天我自己一试，果然请求全部报错了。大概是试用额度到期，或者 NVIDIA 那边调整了接入策略，具体原因不清楚，总之就是用不了了。

## 免费的午餐，本来就吃不太久

NVIDIA 的 API 站点本身是给开发者体验用的，放在它自家 GPU 上跑各家开源模型，目的是让你试完觉得好，乖乖掏钱上 NVIDIA 的云服务。所以它不是什么长期免费的福利，额度用完或者策略一变，说停就停。

社区里隔三差五就有人分享这种"白嫖攻略"，这类途径的共同问题是：你不知道它什么时候关。有些是限了速率，有些是改了接入认证，有些干脆整个模型下架。所以我一直的建议是：白嫖接口可以拿来应急、可以拿来测试，但别把它当主力生产环境用。

不过这次有点可惜。GLM-5.2 在中文任务上的表现确实对得起"国产开源第一梯队"这个名头，如果 NVIDIA 的免费通道真的关死了，想继续白嫖就得再找别的路子了。

## 替补上场：月之暗面 Kimi K3

好在同类型的免费接口不止一家。我现在换上了月之暗面（Moonshot AI）的 Kimi K3，目前用下来感觉还不错，日常对话、写作、代码补全这些场景都撑得住。

Kimi 的长文本能力是它的招牌，拿来读长文档、分析报告、改公众号文章这些活很顺手。速度上响应也算快，不会像某些免费开放接口那样转圈转半天。我的 OpenClaw 已经把它设成了默认模型，之前的 GLM-5.2 正式下岗。

类似的替补选手其实还有几个渠道：CPA 聚合站里还挂着 SenseNova、DeepSeek 等一堆国内模型，restless 的免费额度目前还能正常调用。我自己的降级链配的是 Kimi K3 → DeepSeek → SenseNova，一层不行自动切下一层，基本不会出现"全线瘫痪"的情况。

## 一点心得

折腾 AI 模型这两年，我总结出来一条经验：**永远给自己留一个备胎**。

免费接口会下线，付费服务会涨价，API 格式说改就改。指望一个模型一家接口包打天下，迟早有翻车那天。反倒是"主力 + 备用 + 兜底"这套三层结构最省心——主力用顺手的，备用选稳定的，兜底留个免费第三方。哪天谁挂了，切换只要一分钟。

另外就是别太沉浸在"发现新大陆"的兴奋里。这次 GLM-5.2 就是教训：好用的东西先用着，但推荐给人之前，最好先观察它几天稳不稳定，免得跟读者一起踩坑。
