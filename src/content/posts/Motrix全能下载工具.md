# Motrix v2.0 回归：时隔三年的全能下载器，到底更新了什么

你大概用过 IDM、迅雷、qBittorrent 这些下载工具，各自有各自的脾气。HTTP 链接用 IDM 飞快，BT 种子得换 qBittorrent，磁力链又得另找。能不能一个软件把这些活全包了？

Motrix 一直想干这件事。它基于 aria2 内核，支持 HTTP、FTP、BT、磁力链，界面干净，开源免费。问题是上个版本停更了三年多，不少人以为这项目已经凉了。结果今年作者突然诈尸，直接蹦出一个 v2.0.0-beta.19，用 React 和 TypeScript 把整个项目重写了一遍。

## 这次更新到底改了什么

最直观的变化是界面。v1 长得像个桌面版 AriA2Ng，功能能用但谈不上好看。v2 整个重做了 UI，支持深浅色模式切换，还有一个仪表盘页面可以自己定制，能看到实时下载速度和每日活动记录。视觉上算跟上了这个年代的审美。

引擎方面，内置的 aria2 升到了 1.37.0，加了二进制校验。BT 下载支持种子择选，你可以勾选种子里的部分文件而不是全下下来。Tracker 列表也支持自动同步更新，端口映射走 UPnP/NAT-PMP，不用再手动去路由器里开端口。

网络这块新增了 DNS 解析模式选择——自动、系统、内置 DNS 三种切换。遇到某些 DNS 被污染导致下载慢的情况，换一下解析模式可能就好不少。

几个比较实用的新功能：

一是命令行调用。Motrix 现在支持 `motrix://` 协议和命令行参数调用，写脚本批量下载方便了很多。二是远程配对，手机和电脑可以配对管理下载任务。三是 RPC 密钥从原来的简单口令升级到了 64 位，安全性提了一截。四是配置文件便携存储，直接放 U 盘里到哪台电脑都能用。

还有个大动作——Docker 部署。新版支持用 Docker 跑无头服务，自带 Web 管理面板。这意味着你可以在 NAS 上跑一个 Motrix 服务端，通过浏览器管理所有下载任务。跑 NAS 的人应该能感受到这意味着什么。

## 浏览器接管怎么配

Motrix 本身的下载能力之外，真正好用的是配合浏览器插件接管下载。Chrome 和 Firefox 都支持，安装插件后在设置里填好 Motrix 的 RPC 地址（默认 `localhost:16800`）和路径 `/jsonrpc`，之后浏览器里的下载就会自动交给 Motrix 处理。

有一点要注意：v2 的 RPC 端口从 v1 的 6800 改成了 16800。如果你从旧版升级过来，浏览器插件里的端口配置也得跟着改。

社区里有人提到新版用油小猴（Tampermonkey）的 ARIA2 脚本接管网盘下载不生效。这应该是 RPC 路径变化导致的兼容问题。手动把脚本里的端口和路径改成新版参数就行。旧版能正常配合夸克网盘等工具的配置在迁移时需要留意。

## 哪些人用得上

如果你日常就是下个 HTTP 链接，偶尔下几个 BT 种子，Motrix 一个工具足够了，不用来回切换。比起那些闭源且带广告的下载器，它干净、没有功能限制、不跟你弹窗。

但 BT 下载效果取决于资源本身。谈 BT 下不动的问题——种子做种少、资源老旧冷门，换成什么软件都一样。先看种子活跃度，再检查公网 IP 和 UPnP 有没有正常工作，最后看 Tracker 配置。软件自带的 Tracker 列表够日常用，碰到冷门资源建议手动补一些公开 Tracker。

跨平台也到位了：Windows 10/11 64 位、macOS 12+（M 芯片和 Intel 各有对应版本）、Linux 主流发行版都有。macOS 用户在系统托盘和顶部菜单栏都能看到图标，跟原系统融合得不错。

## 一点想法

Motrix 是开源项目，GitHub 上能看代码，火绒不会拦。如果你对安全性有顾虑，源码翻一遍就清楚了。三年的沉寂之后这波更新质量还不错，不是凑数的。对一个免费工具来说，作者愿意回来继续打磨，本身就是好事。
