# Oracle Cloud免费VPS抢不到？转头申请了Azure教育版，真香

## 01 · 缘起

关注免费云服务器的朋友都知道，圈子里流传着两大神话：**Oracle Cloud 的永久免费 VPS** 和 **Azure 的学生免费额度**。

先说 Oracle Cloud。它家的 Always Free 套餐给 ARM 机型，最高 4 核 24G 内存，还永久免费，听着就像白给。但现实是——**永远抢不到**。

注册的时候区域选哪个哪个缺货，开通 ARM 实例永远提示 Out of capacity。天天蹲点刷新，脚本挂着抢，折腾一个月颗粒无收。这种心情，懂的都懂。

被 Oracle 反复"补刀"之后，我盯上了另一条路：**Azure 教育版**。手上有学生邮箱（edu 邮箱），为什么还要跟几万人抢那几台 ARM 机器？

## 02 · Azure 教育版是什么

微软给在校学生的一项福利，全称 **Azure for Students**，核心权益：

- **100 美元 Azure 额度**，不用绑信用卡
- **每年可续**，续期再送 100 刀（需仍是学生身份）
- 免费套餐里包含 **B1s 规格的 Linux/Windows 虚拟机**（每月 750 小时，够一台 7×24 跑着）
- 还有 MySQL、静态网站托管等一堆服务的免费额度

也就是说，只要有个.edu 邮箱（或者能通过 GitHub 学生包验证），就能合法拥有一台微软云上的 VPS，一年跑不满 100 刀额度的话基本等于白嫖。

## 03 · 申请过程实录

整个过程比想象中顺，梳理成三步：

**① 准备学生身份**

需要一个 edu 邮箱，或者 GitHub Student Developer Pack 里已经认证过学生身份。我用的是学校邮箱，几分钟搞定验证。

**② 注册 Azure for Students**

访问 Azure 教育版入口，用学生邮箱登录微软账号，填写姓名、学校、毕业年份这些信息。这里没有信用卡这一关，纯学生身份验证。

**③ 开通虚拟机**

验证通过后到账 100 美元，控制台里新建虚拟机，选 B1s 规格（1 核 1G）就能吃免费额度。系统选 Ubuntu，区域就近选东亚，SSH 密钥登录，几分钟跑起来。

## 04 · 拿到手能干啥

1G 内存的 B1s 不豪华，但轻量活完全够：

- 搭个**个人博客 / 导航页**
- 跑**青龙面板**、签到脚本这类定时任务
- 装个 **Docker**，挂几个轻量容器练手
- 当**学习 Linux 的练习机**，随便折腾不心疼

跟 Oracle 的 ARM 神机比性能肯定是被吊打的，但一个抢不到、一个稳定到手，选哪个不用纠结。

## 05 · 一些提醒

⚠️ **额度是消耗品**：100 刀花完服务会停，记得在控制台开消费提醒，别开高配机器忘关了

⚠️ **学生身份要诚实**：信息造假被封号不值得，资格到期了该续就续、该退就退

⚠️ **12 个月后**：要么续学生身份再领 100 刀，要么转即用即付，提前想好

## 06 · 闲话

白嫖圈有句老话：免费的才是最贵的——Oracle Cloud 抢不到的时间成本、蹲点刷新的心力，其实早就值回一台低配 VPS 的钱了。

与其跟几万人挤独木桥，不如换条路走。Azure 教育版名额不紧张、流程简单、大厂出品，对学生党来说性价比拉满。

不是学生的也别灰心，Azure 新用户还有 200 美元试用额度，足够折腾一阵。
