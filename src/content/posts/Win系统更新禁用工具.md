# Win11弹窗烦死了？这款工具一键禁用系统更新，还屏蔽升级提醒

你有没有这样的经历：写了一下午的项目，电脑凌晨三点自动重启装更新了，早上打开发现 D 盘数据盘没挂回去，缓存文件丢了一半。或者更糟的——某天打开电脑发现 Windows 11 升级推送已经到位，右下角那个狗皮膏药一样的卡片怎么也关不掉。

吾爱破解论坛网友「啊常用户」最近就碰到了一件让他血压飙升的事：凌晨电脑自动重启装更新，把他正在跑的定时任务给打断了。作者一气之下花了 20 块钱让 Codex 写了个小工具，从 2.0 一路迭代到 3.0 正式版。这帖子三天 18000 多浏览、1300 多回复，热度相当离谱。

## 一晚上写出来的工具，三天迭代到 3.0

起因很普通：作者前一晚给 Codex 发了一批任务，定了休眠关闭。结果第二天早上起来发现电脑被自动重启了——Windows Update 在夜里装了个补丁，顺便把休眠设置改回去了。

这事搁谁都得冒火。作者第一版工具 2.0 用的是 C#/.NET Framework，结果论坛里一群用 Win7 的人跑不起来——原版 Win7 默认不带 .NET 4。第一版就这样被群嘲了一波，作者硬着头皮装了个 PVE 虚拟机测 Win7，又花钱让 Codex 把整个项目重写成原生 C++ 单文件 exe，不依赖 .NET、也不需要 VC++ 运行库。

这还没完。2.1 解决了 Win7 兼容问题，3.0 又加上了 Win10 用户最关心的功能：**阻止升级到 Win11**。工具名也从原来的「自动更新关闭工具」改成「Win7/10/11 自动更新关闭工具 3.0」。

作者自己掏了三次钱（每次 20 块）让 AI 写代码，做出来的东西意外地成熟。这大概是 2026 年 AI 编程平民化最真实的注脚——会提需求、会验证、会改错就行，不用自己写一句代码。

## 工具到底干了什么

核心功能其实就两块：禁用系统更新 + 阻止升级到 Win11。

**禁用系统更新**这一块是 Win7/10/11 通用逻辑：通过修改注册表策略，禁止自动更新、通知、自动重启、驱动更新。Win10/11 改了六项核心策略，Win7 用的是另一套方案——停用 wuauserv 服务、设置 NoAutoUpdate 和 DisableWindowsUpdateAccess。Windows 11 升级屏蔽则用了 ProductVersion、TargetReleaseVersionInfo 这套注册表项，把系统锁定在当前版本，2099 年之前别想自动升上去。

**阻止升级到 Win11**这块是 3.0 版本的核心新增。Win10 用户经常被右下角的「您的设备可以升级到 Windows 11」弹窗骚扰，3.0 增加了独立的「禁止升级到 Windows 11」和「恢复允许升级」按钮。工具会先读取系统的 DisplayVersion、ReleaseId 和真实 Build 交叉校验版本号（支持从 1507 到 22H2 的常见 Build 映射），异常版本直接拒绝写入，避免错误锁定。

工具还做了几件事看着不起眼但很关键：每次写入后重新读取确认；某步失败会回滚到本次操作前的状态；备份文件存到 `%ProgramData%\UpdateLock\` 目录下，限定 SYSTEM 和管理员才能访问；64 位系统明确操作正确的注册表视图，防止读写错位。

如果你哪天后悔了想恢复更新，工具也提供「恢复」按钮——它会从备份文件里逐项回读原始值，全部验证正确后才删除备份，确保回退到关闭前的状态。

## 用起来要注意什么

单文件 exe，下载下来双击运行就行，软件自动识别当前系统版本，Win7/10/11 走不同分支。Win7 用独立控制方案，Win10/11 用核心策略。Win11 直接禁用「禁止升级」功能，因为本来就是 Win11 没必要升级。

几个**坑要提前知道**：

- **不要在刚装完系统就禁用更新**。先让 Windows Update 跑一段时间，把基础补丁和驱动都打齐了再关。作者原话：「我建议大家把电脑折腾好以后再去禁止更新，前期的更新你就让他去更新。」
- **USB 设备驱动问题**。关闭更新后再插入新 USB 设备可能拿不到驱动，所以前期更新别急着禁。
- **Win10 设置里的 W11 卡片可能还在**。即使已经屏蔽升级，设置页面那个 W11 卡片还是显示，实际已经没有作用——这是微软的设计，作者也拿它没办法。
- **不支持 Windows Server**。只在 Win7/10/11 工作站系统上能用，Server 系统会直接拒绝。

整个工具用 Codex 全程编写，作者在帖子里特意声明「不存在什么后门病毒啥的」，源码他也有计划开源（不过发帖当天熬太晚没更上去）。

## 一点想法

关系统更新这事争议不小。微软的逻辑是「安全补丁很重要」，用户的逻辑是「半夜重启这事更可怕」。工具不站在哪一边，它只是给那些已经决定要禁用更新的人一个干净的实现。

最有意思的其实是作者的迭代过程。2.0 → 2.1 → 3.0，每次迭代都解决了用户反馈的真实问题——Win7 不兼容、Win11 屏蔽不彻底、界面按钮没灰显。三次付费让 AI 重写代码，每次都针对群友吐槽的具体场景。这种「AI 出活 + 人验证 + 群友吐槽驱动迭代」的开发节奏，比传统闭门造车快得多。

最终的工具也只有一个 exe，几十 KB 大小，做的事情足够精准。对于怕折腾、又想根治自动更新烦扰的人来说，这款工具值得一试。
