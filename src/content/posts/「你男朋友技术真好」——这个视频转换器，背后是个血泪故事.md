# "你男朋友技术真好"——这个视频转换器，背后是个血泪故事

在吾爱破解看到一个帖子，标题就把我逗笑了：**solong视频转换器 V2.1 - 她闺蜜说"你男朋友技术真好"，桌上安静了两秒。**

点进去一看，果然是个程序员被女朋友和七大姑八大姨的视频转换需求逼到"赎身"的血泪史。

---

## 01 一切的开始：帮女朋友转第一个文件

帖子的作者是吾爱的老用户，之前发过一个音频转换器，也是被女朋友的音频转换需求逼出来的。这次视频转换器，依然是同一个惨痛教训：

> 千万不要帮她转第一个文件。因为帮了第一个就会有第二个。有了第二个就会有第三个。有了第三个她闺蜜就知道了。她闺蜜知道了她同事就知道了。她同事知道了她同事的七大姑八大姨都知道了。你以为你在帮女朋友忙，实际上你在给自己挖一个巨型客服中心。

事情是这样失控的：起初只是帮女朋友转一个 MOV 到 MP4，十秒搞定。然后是 4K 视频太大要压缩，然后是旅游回来三十多段全要转。到这一步还在可控范围内——直到她闺蜜出现了。

闺蜜做小红书，导出视频太大上传超时，问他怎么办。他说"降低一下导出码率"，对方回了一句：

> "什么是码率？听起来好难，你帮我弄一下嘛~🥺"

然后闺蜜发了个朋友圈："闺蜜的男朋友是程序员真的太香了"。女朋友看到以后问："她发什么朋友圈？你帮她弄什么了？"

再后来吃饭的时候，闺蜜当着女朋友的面说了一句"你男朋友技术真好"——桌上安静了两秒。

---

## 02 事情是怎么彻底失控的

你以为到这里就完了？没有。

作者回家吃饭，妈妈随口问了一句"你在电脑上整天捣鼓什么呢"，女朋友抢答："他会把视频转格式，可厉害了。"妈妈马上接话："那正好，家里有一批老 DV 录像能不能帮忙转一下？"阿姨也在："我那也有几个视频格式不对，打不开。"

某个周末晚上，作者想打会儿游戏。女朋友发来两个文件，闺蜜微信响了，妈妈转发了一个文件。二十分钟之内三个人找他转视频——游戏启动器都没点开。

那一刻他想通了：**唯一的解法，是做一个工具，甩给她们，让她们自己转。**

## 03 solong 视频转换器：核心就三步

拖文件进来 → 选格式（或直接选预设） → 点转换。完事。

所有参数都有默认值，不懂就别动，直接转。想调的人随便调——编码器、画质、分辨率、GPU 加速全都能改。小白直接用，老手随便调。

**三大模式**：转换、合并、截取。转换是主力，几百个一起排也没事；合并能把几段拼成一个，参数一致的话直接秒级无损拼接；截取就是剪头尾或中间一段，自带帧预览和双滑块时间轴。三个模式都能暂停，打局游戏再接着转也行。

**60+ 预设**：抖音、快手、小红书、微信视频号、朋友圈、B 站、YouTube、Instagram、Twitter……主流平台都有。点一下就完事，不用管码率、分辨率、像素格式这些词。预设可以设为默认，自己调出的配置能另存为预设，还能导出 JSON 带到别的电脑。

**格式支持**：视频容器 MP4 / MKV / MOV / WebM / AVI / FLV / WMV / TS / MPG / 3GP / OGV；音频能扒成 MP3 / M4A / FLAC / WAV / OGG / OPUS；动图能做 GIF / WebP / APNG / AVIF，还有 OBS 用的带透明通道的 WebM。

**编码器**：H.264 / H.265 / AV1 主流全支持，苹果 ProRes、Avid DNxHR、无损 FFV1 / UT Video 也有，老兼容的 MPEG-4 / DivX / Xvid 一个不少。一共 19 种，够用了。

**GPU 加速**：N 卡、A 卡、Intel 三家都支持（NVENC / AMF / QSV），自动检测。

**其他细节**：分辨率帧率画面比例都能调，9:16 / 4:5 / 3:4 / 6:7 各平台竖版尺寸全支持；水印能加文字或图片，预览里拖动定位，想去台标拖个红框就行；字幕能保留、烧录、移除，同名 .srt / .ass 自动识别；音量 10%-400%、响度一致化、多音轨切换；章节能读能改，按章节自动拆分文件；偶尔用得上的 3D LUT 色彩校正、滤镜、防抖、降噪、淡入淡出也都有。

## 04 一个没想到的转折

帖子最后提到一件事。

作者帮妈妈转那批老 DV 录像——AVI 格式，十几二十年前拍的，小时候过生日、过年放炮、幼儿园表演、学骑自行车。两百多个文件，手机上根本打不开。

他把整个文件夹拖进工具，选 MP4，点开始，去陪妈妈打牌。一个多小时回来，全部转完。那天晚上妈妈拿着手机看了一整晚，眼眶红红的。

作者说，突然觉得这工具不只是"赎身"用的。**有些老文件转过来，存的不是数据，是记忆。**
