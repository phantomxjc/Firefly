# 免安装解压神站！RAR、7Z、APK拖进浏览器就能解

你有没有遇到过这种场面：同事甩过来一个 .rar 或者 .7z 文件，你电脑上除了 Windows 自带的压缩功能啥都没有，双击直接报错。装个解压软件吧，安装包弹窗广告一大堆，装完还顺手送你三个浏览器插件。就为了一个压缩包，电脑被折腾半天，说实话挺憋屈的。

今天分享的这个站叫 ExtractFree，一个免费的"在线解压"工具。不用装任何软件，打开网页，把压缩包拖进去，它直接在浏览器里帮你解开。

## 网站是啥来头

ExtractFree 的界面干净得有点不像话——首页就是一个上传框，没有任何花里胡哨的东西。它支持的格式多到离谱，官网把格式分类列了一整屏：

- ✦ 常见的：ZIP、RAR、7Z、GZ、XZ、BZ2、ZST
- ✦ Linux 系的：TAR、TAR.GZ、TGZ、TAR.BZ2、CPIO 这些
- ✦ 安装包类：APK、MSI、EXE、DEB、RPM、CAB、WIM
- ✦ 电子书类：CBZ、CBR、EPUB、CHM
- ✦ 镜像类：ISO、VHD、UDF、CSO

注意看"安装包类"这一栏，APK 和 EXE 都能解。安卓玩家想扒 APK 里的素材、音效，直接拖进浏览器就能拿到，不需要再去折腾反编译工具链。

## 用起来啥感觉

流程就三步：打开网站 → 拖文件 → 下载里面的内容。它还专门给每种格式做了子页面，比如你有 RAR 文件就直接进"RAR解压"那个页面，细节做得挺用心。

多语言支持也很全，中文简体、繁体、日文、英文都有，看起来是个正经在做全球化的团队。

要提醒一句：在线工具的原理注定了它不适合解压特别大的文件，也不建议传涉及隐私的压缩包。日常救急、临时处理办公室发来的怪格式，才是它的主场。

## 适合谁

- ✦ 公司电脑不让装软件的打工人
- ✦ 用 Mac 收到 RAR 愣住的朋友（macOS 原生不解 RAR）
- ✦ 想拆 APK 看里面资源的折腾党
- ✦ 手机、平板上临时要解压的人——浏览器能开就能用
