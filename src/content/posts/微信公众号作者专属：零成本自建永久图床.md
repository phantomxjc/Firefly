## **一、公众号作者的 4 大图床之痛**

如果你写过公众号，下面这些场景一定不陌生：

1. **素材库卡到怀疑人生**：图片越堆越多，打开一篇文章要加载 20 秒。
2. **换电脑就找不回原图**：历史文章的配图找不到，改文章只能重新配图。
3. **第三方图床突然全挂**：某天起床发现所有外链失效，文章集体"失明"。
4. **笔记软件图片同步失败**：Obsidian / Typora 笔记想一键发公众号，图片总是出问题。

💡 **核心公式**：自建图床 = 自己的域名 + 免费云存储。外链永久有效、微信不拦截、全球加载快。

## **四、Step 2：CF Pages 部署（5 分钟）**

登录 Cloudflare → Workers & Pages → 创建 → Pages → 连接 Git → 选你 Fork 的仓库。

⚠️ **下面配置一字不差照抄**，错一个字段都可能部署失败：


| **配置项** | **正确值** | **常见错误** |
| ---------- | -------------- | ----------------------- |
| 框架预设 | None | 误选 React / Vue |
| 根目录 | / | 改成 functions 或 frontend |
| 构建命令 | npm install | npm run build（根目录无此脚本） |
| 构建输出目录 | /frontend-dist | /dist 或 /build |
| Node.js 版本 | 22.x | 低于 18.x 可能报错 |


⚠️ 点击「保存并部署」后第一次会**部署失败**——这是正常的，因为还没绑定存储，继续下一步即可。

---

## **五、Step 3：绑定存储（5 分钟，最关键一步）**

进 Pages 项目 → 设置 → 绑定，添加 **2 条必填绑定**。这一步是很多人卡住的地方，请格外小心。

[https://img.xjc.ccwu.cc/file/微信公众号/微信公众号作者专属：零成本自建永久图床/1783426042968_QQ20260707-200357.png](https://img.xjc.ccwu.cc/file/微信公众号/微信公众号作者专属：零成本自建永久图床/1783426042968_QQ20260707-200357.png)

### **① KV — 存后台配置**


| **字段** | **正确值** |
| ------ | ----------------------- |
| 变量名 | `KV`（代码里读 env.KV，别写成别的） |
| 类型 | KV Namespace |
| 命名空间 | `img_url` |


### **② R2 — 公众号主力存储（免费 10GB）**


| **字段** | **正确值** |
| ------ | ------------------------------ |
| 变量名 | `img_r2`（必须是这个！代码读 env.img_r2） |
| 类型 | R2 Bucket |
| 存储桶 | `img_r2` |


⚠️ **绑定完成后，务必返回「部署记录」→ 最新那条 → 点击「重试部署」。不重部署绑定不会生效！**

## **六、Step 4：自定义域名（3 分钟）**

这一步让图片用你自己的域名访问，而不是 Cloudflare 的随机域名，更专业、更可信。

### **1. Pages 侧挂域名**

Pages → 你的项目 → 自定义域 → 设置域名 → 填 `img.yourname.com`（换成你自己的）→ CF 会自动加 DNS 记录。

### **2. R2 侧开公共访问**

CF → R2 → 你的桶 → 设置 → 公共访问 → 启用 → 复制 `https://xxx.r2.dev` 域名。

⚠️ **不开公共访问，图片会返回 403！**

### **3. 后台配置 R2 渠道**

访问 `https://img.yourname.com/dashboard` → 系统设置 → 上传设置 → 添加渠道 → R2：

- 桶名称：填 R2 桶名（如 `imgbed-bucket`）
- 公共访问链接：粘贴 `https://xxx.r2.dev`
- 启用：✅ 打开

## **七、效率翻倍：三个实操技巧**

### **技巧 1：配 PicGo 一键传图（写文章神器）**

PicGo → 插件市场 → 搜 `cf-imgbed` → 配置：

- 域名：`https://img.yourname.com`
- 上传路径：`/upload`
- 认证码：后台「安全设置」中设置的密码（可选，防乱传）

🎯 **效率对比**：

- 以前：截图 → 保存到本地 → 上传公众号后台 → 复制地址（30 秒）
- 现在：截图 → Ctrl+Shift+P → 自动出外链，直接粘贴（3 秒）

### **技巧 2：图片命名规范（方便管理）**

后台开启「时间戳重命名」，文件自动变成：

```
1782889518764_mysql读写分离原理.png
```

时间戳 + 原始文件名，既不会冲突，又能一眼看出是哪篇文章的图。

### **技巧 3：备份策略（双重保险）**

- 🎯 **R2 主力**：免费 10GB，够用 5-10 年，日常上传全部走 R2
- 🛡️ **Telegram 兜底**：后台再开一个 TG 渠道，R2 满了自动切 TG，永不丢图

## **八、常见问题（踩过的坑都帮你避了）**


| **问题** | **原因** | **解决** |
| ------------------------------ | ------------------------- | ---------------- |
| 部署时报 `frontend-dist not found` | 构建输出目录没填 `/frontend-dist` | 回去改配置 |
| 上传失败，日志 `R2_BUCKET_NOT_FOUND` | R2 绑定变量名不是 `img_r2` | 改成 `img_r2` 并重部署 |
| 图片 403 打不开 | R2 没开公共访问 | R2 桶设置里启用公共访问 |
| 后台进不去 | KV 没绑或变量名错 | 确认 KV 变量名是 `KV` |
| 部署一直失败 | 绑定后没重部署 | 部署记录 → 重试部署 |
