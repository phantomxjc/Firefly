# 微信锁屏助手：离开电脑再也不怕聊天记录被看了

你有没有这种经历：在办公室起身去倒杯水，按了 Win+L 锁屏，但忘了锁微信。正好同事走过来说要查个资料，你没多想就把锁屏密码报给了他。等回来一看，微信聊天窗口还亮在屏幕上，心里咯噔一下。

又或者，你在用远程桌面连着另一台电脑跑活，那台机器微信登着，你从这边锁了屏，可那边的微信根本没锁——聊天记录就这么敞在那儿。

吾爱破解论坛网友 yangcongs 就碰到了一模一样的事。他翻遍论坛只找到两个工具，要么不兼容自己的微信版本（3.9.12.57），要么功能对不上。索性找 AI 代劳，把自己的需求一条一条丢给 AI，来回调试四天，最终做出了这个31KB的小工具——WeChatLock。

## 31KB能干什么

这个工具的核心逻辑就一句话：你要锁屏的时候，先把微信锁上，再锁电脑。但实际做起来要处理的事远比这复杂。

第一个功能是拦截 Win+L。按下 Win+L 的瞬间，程序先拦住这个按键组合，把微信激活到前台，发送 Ctrl+L 锁定快捷键，确认微信锁上了，再放行 Win+L 锁定电脑。因为电脑进入安全桌面之后，模拟按键到不了微信窗口，所以必须先后倒过来做。

这中间有个小瑕疵：Win 键释放的时候偶尔会弹出开始菜单，程序会补发一个 ESC 把它关掉，所以锁屏时你会看到开始菜单闪一下。不算什么大问题，但不至于假装没看见。

第二个功能是空闲超时检测。如果你没主动锁屏，但人已经离开了，程序会监测你有没有动鼠标键盘。空闲超过设置的时间（默认1分钟），它就主动去检查微信锁没锁，没锁就帮你锁上。检测的方式是调用 Windows 的 UI Automation API，看微信主窗口里有没有"Windows 微信已被锁定"这段文字。

第三个功能是我觉得最有用的一个——补锁机制。锁屏时如果微信没锁成功，程序会记一笔"待锁定"。等你解锁电脑的时候，第一件事就是补锁微信。这个场景对远程桌面用户太实用了：你在A电脑关掉远程连接，B电脑触发锁屏事件，微信没锁上也没关系；等你重新连上去的时候，B电脑解锁的一瞬间就会把微信锁住。

## 用起来怎么样

下载下来双击运行，图标出现在右下角托盘。右键点图标，可以设置开机自启、自定义微信锁定快捷键（不一定是 Ctrl+L）、调空闲时间阈值（1到60分钟都行）。

不用安装，不写注册表，配置文件就一个 config.xml，跟 exe 放在同一目录。整个程序31KB，一个单文件，U盘拷着走都行。

需要留意几点：软件适配的是微信3.9.x版本，如果你用的是4.x的新版微信可能不兼容；程序自带 .NET 依赖，老系统可能需要装运行环境。另外作者在帖子里也说了，如果有人趁你不在把软件退出了，那确实没辙——这种明摆着要翻你微信的人，靠一个工具也防不住。

## 一点想法

作者在帖子里说了句挺实在的话："整个项目我个人完全没有写一句代码，全程都是跟AI沟通。" 四天时间从需求到成品，AI写代码这件事已经不再是概念了。

这个工具解决的也不是什么惊天动地的安全问题——它就是堵住了一个日常小漏洞。但正是这种小漏洞，平时不在意，出了事又说不清楚。31KB的体积，做的事情是值当的。
