## 01 · 缘起

学 SQL 这件事，每个人都会在"环境搭建"这一步卡住。

装 MySQL？版本对不上。装 Docker？报错看不懂。配环境变量？百度了三小时还没跑起来。最后安慰自己：算了，先不学了。

其实有个更简单的路——找个在线的 MySQL，用完就走，不留痕迹。

最近发现了一个叫 SQLPub 的平台（sqlpub.com），专门提供免费在线 MySQL 实例，注册就能用，不需要任何配置。

## 02 · 规格

免费版的参数：

| 规格项 | 参数 |
|---|---|
| 存储空间 | 500 MB |
| 请求频率限制 | 36000 次 / 小时 |
| 最大连接数 | 30 个 |
| 节点区域 | 中国大陆节点（免费版） |

对于日常练习、临时测试、写课程作业来说，500MB 完全够用——几千条记录随便存。

## 03 · 惊喜

SQLPub 不只是一个在线数据库，它还自带一个在线客户端，而且内置了自然语言转 SQL 的黑科技。

什么意思？就是你直接输入：

> "帮我查一下上个月销售额超过一万的用户"

它直接给你生成对应的 SQL 语句，还能直接执行。这对 SQL 新手来说，相当于有个 24 小时在线的数据库老师。

当然，如果你用的是 Navicat、DBeaver 这类专业工具，也可以直接连——把主机地址、端口、用户名密码填进去，和操作本地数据库一模一样。

## 04 · 适合谁

- ✦ 📚 **SQL 初学者**：不用搭环境，打开网页就能写 SELECT，不用装任何东西
- ✦ 💻 **临时测试需求**：跑一个临时脚本、验证一段 SQL 逻辑，用完不管，省心
- ✦ 🔗 **接 Navicat 做开发**：用惯专业工具的开发者，完全可以把它当作远程测试库来用
