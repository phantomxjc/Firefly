# 有没有想过，养一只桌面宠物陪你打字？

标签：趣味工具

有没有这种感觉：

上班的时候对着电脑敲字，敲着敲着就觉得很枯燥。特别是周末还要加班，对着屏幕发发呆，键盘敲了半天也不知道在敲什么。

今天介绍一个有点「不正经」但意外好玩的桌面工具——BongoCat。

## 它是什么

BongoCat 是一只住在你桌面上的小猫。

打开之后，桌面上会出现一只卡通猫。**你敲键盘，它跟着敲；你动鼠标，它跟着动。**

不是 GIF 动画，是实时互动的——猫的爪子会配合你实际的敲击节奏，看起来就像你们在一起「合奏」。

灵感来自 MMmmmoko 的 Bongo Cat Mver，由开发者 ayangweb 基于 Tauri 框架重新实现，目前在 GitHub 上有大量开发者参与贡献。

## 几个好玩的点

### 01 敲键盘，它在陪练

打字的时候，屏幕角落有只猫在「帮」你一起敲。

有时候觉得自己不是在和文档战斗，是在和这只猫合奏。

### 02 支持自定义模型

默认的猫当然可爱，但如果你想换个形象？

BongoCat 支持导入自定义模型。GitHub 上有大量第三方模型：原神角色、游戏主播形象、动漫人物……换成自己喜欢的样子，打字都多了几分动力。

### 03 上了 Steam

是的，这只猫不止免费开源，它还上了 Steam。

Windows 用户可以在 Steam 上找到它，通过每千字可以兑换的方式获取挂件和皮肤。当然，Steam 版和 GitHub 免费版是同一个东西，区别不大。

### 04 跨平台支持

macOS、Windows、Linux 都能用。

不管你用什么系统，下载对应版本，双击打开就能看到这只猫。

### 05 开源、不收集数据

代码在 GitHub 上完全公开，隐私方面不用担心——它不需要联网，不会上传你的数据，纯粹是本地工具。

## 适合谁用

- **直播博主**：桌面有只猫陪你敲键盘，观众看着有意思
- **加班党**：周末对着电脑发愁，有只猫一起发呆，心情会好一点
- **程序员**：敲代码的时候有猫「陪练」，仪式感拉满
- **极客玩家**：换各种第三方模型，折腾停不下来
- **摸鱼爱好者**：正经工具它不算，但真的解压

## 几个提醒

BongoCat 运行的时候，会在你操作系统里申请「输入监控」权限，这样它才能检测到你的键盘输入。这是正常权限，不是木马。

不过说实话，**这类桌面宠物工具，安全性靠开发者自觉**。BongoCat 是开源项目，有能力的话可以看看它的源码再决定用不用。

## 茶余饭后

写到这里，突然有点感慨。

现在的软件都越做越大，越做越「重」。一个工具恨不得装下所有功能，占满你的屏幕、后台、开机自启。

反而是 BongoCat 这种「小而美」的东西，让人觉得舒服。

它没有 KPI，没有日活压力，不打算变成平台。它只是安安静静地躺在你桌面角落，你敲键盘的时候它跟着动一动，你发呆的时候它也发呆。

某种意义上，这种「无用」的东西，反而是最治愈的。

周末加班的时候，别忘了还有只猫在陪你。
