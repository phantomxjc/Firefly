## 01 · 缘起

新买电脑开机 8 秒，用一年开机 45 秒，再战两年得去泡杯茶等它慢慢醒。

C 盘空间越来越小、后台莫名其妙一堆进程、隔三差五弹个广告、Win11 右键菜单比以前多了两层……这些"慢刀子割肉"式的体验，很多人最后的解法是——重装系统。

但系统优化不该只有重装一条路。今天要聊的开源小工具 ZyperWin++，只有 5MB，绿色免安装，GitHub 上拿了 8000+ 星标，可能就是那个让你不用重装也能"回到出厂速度"的东西。

## 02 · 来头

ZyperWin++ 是国内开发者 ZyperWave 在 GitHub 上开源的 Windows 优化工具，基于 .NET Framework 4 + C# 开发，整个软件包才 2~5MB，解压即用，不写注册表、不装运行库（Win7 除外）。

覆盖系统从 Win7 SP1 到最新的 Win11，老电脑新机器通吃。当前最新版 v4.1，GitHub 上 8000+ Stars、400+ Forks，社区活跃度不错。

和市面上"全家桶式"优化软件最大的区别：**代码完全开源**，所有优化项都可查看源码，不存在偷偷塞东西的问题。而且它默认不勾选任何优化项，让你自己看清楚再决定。

> 💡 一句话定义：ZyperWin++ = 轻量级系统优化工具箱（性能调优 + 服务管理 + 垃圾清理 + 系统激活 + Office 部署），全部装在一个 5MB 的绿色 EXE 里。

## 04 · 三档

ZyperWin++ 把一键优化分成三个级别，思路很清晰——不是"能快就行"，而是告诉你会关掉什么：

1. **基本优化**：轻量调校，提升流畅度与界面体验，保留稳定性和安全更新。日常使用选这个就够
2. **深度优化**：平衡性能与功能，关闭冗余后台服务。适合办公、游戏场景，部分功能会受影响
3. **极限优化**：极致性能压榨，彻底关闭安全组件（包括 Defender）。仅推荐纯净游戏环境，风险自担

不信任一键优化的话，还有自定义模式：逐项勾选，每个选项都配了说明文字，告诉你具体会改什么。相比那些"一键优化至于改了啥你自己猜"的软件，这点已经赢了太多。

> 💡 关于还原：优化前可以导出当前配置。优化后哪个功能不正常了，随时导入配置一键还原，不用重装系统。

## 05 · 安全吗

聊系统优化工具，安全永远是第一位。ZyperWin++ 做了几件事：代码完全开源、不写注册表、绿色免安装、优化前可备份、支持导入导出配置、优化项自带说明。

> ⚠️ 关于杀毒软件误报：系统优化工具涉及读取、修改注册表，禁用服务和计划任务，被 360 / 火绒 / Defender 报"潜在风险工具"是正常现象。建议始终从 GitHub Releases 下载，核对版本号和哈希值；不放心就直接下源码自己编译审查。作者在项目里也贴了 virscan.org 的查毒扫描结果。

## 06 · 上手

1. 去 GitHub Releases 下载最新版，解压即用，无需安装
2. 右键 → 管理员运行（涉及 HKLM 注册表和服务操作）
3. 先导出配置备份，养成好习惯
4. 新手选"基本优化"，老手逐项勾选自定义
