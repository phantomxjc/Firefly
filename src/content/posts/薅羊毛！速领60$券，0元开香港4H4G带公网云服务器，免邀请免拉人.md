## 01 · DGN Cloud 是啥来头

DGN 团队最早做的是香港本地 IDC——机柜、带宽、物理服务器运维这些脏活累活都干过。后来攒够了经验，干脆做了个自服务云平台，控制台和 API 都是自研的。

现在的产品线很精简：**云服务器（Cloud Server）、云硬盘（Cloud Disk）、弹性公网 IP（Elastic IP）、共享流量包（Shared Traffic Package）**，就这四样，没有云数据库、没有乱七八糟的 PaaS。

云服务器当前只有一个区域——**香港 Zone 1**，Premium BGP 线路，公网出口走 BGP 优质路由。同区域不同账号之间用 VPC 隔离，私密流量不走公网。

简而言之：底子扎实，线路靠谱，规模不大但服务稳定。

## 02 · 这羊毛到底怎么薅

步骤简单，5 分钟能开起来一台。

**第一步，注册账号。**

打开 `https://app.dgnlinks.com/console/login`，邮箱注册一个账号，验证邮箱就完事。**全程不要信用卡、不用实名认证**（可能部分地区会要求，建议用海外邮箱注册最省事）。

**第二步，领取 $60 新人券。**

注册成功后到控制台首页/活动中心，新用户会看到一张 **$60 消费券**，自动到账。这张券的细则要看控制台显示，我这边看到的是：

- 仅限新用户（每个邮箱/账号一次）
- 可用于云服务器、弹性 IP、共享流量包等付费产品
- 有有效期，**以控制台显示为准**，建议领完就开机器，别放着
- **不需要邀请码、不需要拉人、不需要绑卡**

**第三步，开 4H4G 香港机器。**

进 `Compute → Cloud Server → Create`，区域选 Hong Kong Zone 1，规格选 **c1a.x4medium**：

- 4 vCPU
- 4 GB 内存
- 20 GB 系统盘（SSD）
- 月付 $14.20 / 小时 $0.0198

镜像随便选，Ubuntu 22.04 / Debian 12 / CentOS Stream 都能装。SSH 密钥在控制台 `SSH Keys` 里新建一个，把公钥贴进去，创建时勾上。

**第四步，开弹性公网 IP（可选）。**

默认创建出来的实例**只有内网 IP**，要带公网还得挂弹性 IP。进 `Network → Elastic IP → Allocate`，选 Hong Kong Zone 1 的 IPv4，会拿到一个公网地址。回到云服务器详情页，把这个公网 IP **绑定**到实例上，就有了。

> ⚠️ **重要提醒：弹性 IP 按流量计费。** 进出双向都算，公网流量是单独算钱的，不是 $60 券全包。建议新人先开个 **Shared Traffic Package**（共享流量包），一次性买断流量池，整个组织下的 IP 都能用——比裸扣 IP 流量便宜很多。

## 04 · 几个实测才懂的细节

**✦ 关机 ≠ 释放**

控制台支持 Stop（关机）和 Release（释放）两个动作。**Stop 状态不收计算费，但公网 IP 和系统盘继续计费**；Release 才彻底停止所有扣费。建议临时不用就 Stop，永久不用才 Release，删了就没了。

**✦ 公网 IP 解绑不释放会继续扣**

弹性 IP 解绑到云服务器后，**只要 IP 还存在就持续按资源费+流量费**。彻底不想要了记得点 Release，否则会一直扣钱到券扣完，再扣钱包。

**✦ 共享流量包是真省**

如果是个人玩玩，单独开 IP + 流量计费一个月下来经常比机器还贵。**Shared Traffic Package** 是组织级别的共享池，一次性买断一个容量，所有同区域 IP 共享用，性价比高得多。具体包大小控制台有得选。

**✦ 控制台有 API**

DGN 公开了 OpenAPI，支持 Bearer Token 认证，账号、SKU、可用区、镜像、Cloud Server 生命周期都有接口。想自动化管理（自动开/关/销毁）直接调 API，写个 cron 脚本就行。文档在 `dgnlinks.com/docs`。

**✦ 工程师工单有时段**

工单 24×7 都能提，但工程师处理是 **HKT 09:00-12:00 和 14:00-19:00** 两个窗口。境外用户算好时差别半夜催，紧急情况可以发业务邮箱。

## 05 · 它不完美的地方

**① 只有一个区域。** 香港 Zone 1，境外业务还行，国内访问延迟看你运营商。如果你想要美西、东京、新加坡，得等官方开新区域，目前还没时间表。

**② 云数据库没上线。** 想跑 MySQL / Redis 得自己装，DBA 活儿自己干。

**③ 4H4G 已经是公开规格里的最大号了。** 没有 8H16G 这种更高规格，重负载场景别指望。

**④ 新厂商，运营时间不算长。** 适合薅羊毛、跑学习项目，重要生产数据建议再观察一段时间。
