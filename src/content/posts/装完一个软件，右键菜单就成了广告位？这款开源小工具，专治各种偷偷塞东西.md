装完一个软件，右键菜单就成了广告位？这款开源小工具，专治各种偷偷塞东西

📅 2026-07-30    ⏱ 阅读约 6 分钟

你有没有过这种抓狂瞬间——

装个看图软件，右键菜单多出三项；
装个网盘，此电脑里又冒出一个图标；
装个办公软件，开机启动、文件关联、浏览器插件全给接管了；
更过分的是，有些下载工具隔三差五把自己塞回开机启动。

关键是，它从来不大大方方问你一句："我要往系统里加这些东西，可以吗？"

如果你受够了这种"被安排"，今天这款开源小工具值得关注——RogueCleaner（流氓软件克星），作者 aakk007。

01它到底是干什么的？

一句话：扫描 Windows 里常见软件偷偷加的右键菜单、"此电脑"入口、自启动、计划任务、服务、浏览器插件、文件关联等项目，然后让你自己勾选确认后清理。

它不是那种"全家桶一键卸载"的大锤工具——重点是把那些不该偷偷留下的小动作拎出来，让你看得懂、选得明白、删得放心。

扫描结果每一条都会告诉你：

① 它在哪里冒出来
② 你会看到什么
③ 它大概是谁家的
④ 工具会怎么处理
⑤ 能不能清理
⑥ 清理前有没有备份

💡 设计原则：默认打开程序不会清理任何东西，扫描结果也不会默认全选。是否清理，全由你自己确认。

02v2.0.11 这次更新了什么？

我看了一眼更新记录，这次主要是把"看得见的体验"做细了：

🆕 补上扫描异常证据报告
界面扫描失败时会写入 scan-error-*.json，反馈问题不用只靠一句"扫描失败"猜原因了。

🆕 "此电脑 / 资源管理器"网盘入口清理
覆盖百度网盘、夸克网盘、WPS 云盘等常见同步入口，"此电脑"里那一排图标总算能清干净了。

🆕 补齐钉钉、夸克网盘等右键规则
"上传钉钉并打开"、"上传到夸克网盘"、夸克 PDF、万能转换这些常用入口都在覆盖范围。

🔧 移除首次运行的桌面快捷方式提示
不再写桌面 .lnk，减少 360 / 火绒对快捷方式创建行为的拦截——熟悉国产安全的同学秒懂。

🔧 发布包改为直出 EXE + 透明 RAR + 源码 RAR + SHA256 校验
下载到本地能直接核对来源，不用怀疑是不是被替换过。

04它的安全边界，值得说清楚

这个工具的原则，作者写得很直白：宁愿少删，也不乱删。

它不会做的事，逐条对照：

默认卸载主程序
删除用户文档
改写 UserChoice
强行绕过自保护
联网上传数据
常驻后台

它会做的事：

清理前先备份
清理后复核
失败时留在复扫列表
原生 C# WinForms EXE
不加壳 / 不混淆
不内嵌脚本

⚠️ 关于安全软件误报：
这个工具会读取、备份、删除注册表项，禁用服务和计划任务，还要检查右键菜单和浏览器外部宿主。360 / 火绒 / Windows Defender 把这类工具归到"系统工具 / 清理工具 / 潜在风险工具"不奇怪。

建议：下载后先核对文件名和 SHA256 校验值，介意的可以直接下载源码包自行审查或编译。

05怎么用？三步搞定

1
下载单文件 EXE
建议从 GitHub Release 下载，核对文件名和 SHA256

2
双击运行，点"开始抓现行"
涉及 HKLM / 服务 / 计划任务，建议用界面里的"管理员模式"重新打开

3
看清楚每一项，自己勾选要清理的
"在哪里冒出来 / 用户看到什么 / 怎么处理"，每条都标得明明白白

∞写在最后

说真的，"被安排"这事最让人难受的不是不能卸载，而是你根本不知道它在你电脑里悄悄做了什么。

RogueCleaner 让我喜欢的一点是：它先把真相摆在你面前，再让你自己决定清不清——而不是替你一键解决。
