## 01 · 缘起

你有没有过这种抓狂瞬间——

装个看图软件，右键菜单多出三项；装个网盘，此电脑里又冒出一个图标；装个办公软件，开机启动、文件关联、浏览器插件全给接管了；更过分的是，有些下载工具隔三差五把自己塞回开机启动。

关键是，它从来不大大方方问你一句："我要往系统里加这些东西，可以吗？"

如果你受够了这种"被安排"，今天这款开源小工具值得关注——RogueCleaner（流氓软件克星），作者 aakk007。

## 02 · 原理

一句话：扫描 Windows 里常见软件偷偷加的右键菜单、"此电脑"入口、自启动、计划任务、服务、浏览器插件、文件关联等项目，然后让你自己勾选确认后清理。

它不是"全家桶一键卸载"的大锤工具——重点是把那些不该偷偷留下的小动作拎出来，让你看得懂、选得明白、删得放心。

扫描结果每一条都会告诉你：它在哪里冒出来、你会看到什么、它大概是谁家的、工具会怎么处理、能不能清理、清理前有没有备份。

> 💡 设计原则：默认打开程序不会清理任何东西，扫描结果也不会默认全选。清不清，全由你自己确认。

## 03 · 更新

v2.0.11 这次更新，主要把"看得见的体验"做细了：

- ✦ 🆕 **补上扫描异常证据报告**：扫描失败时写入 scan-error-*.json，反馈问题不用只靠一句"扫描失败"猜原因
- ✦ 🆕 **"此电脑"网盘入口清理**：覆盖百度网盘、夸克网盘、WPS 云盘等常见同步入口，那一排图标总算能清干净
- ✦ 🆕 **补齐钉钉、夸克网盘等右键规则**："上传钉钉并打开""上传到夸克网盘"这些常用入口都在覆盖范围
- ✦ 🔧 **移除首次运行的桌面快捷方式提示**：不再写桌面 .lnk，减少安全软件拦截
- ✦ 🔧 **发布包改为直出 EXE + SHA256 校验**：下载到本地能直接核对来源，不怕被替换

## 04 · 覆盖

扫描范围基本把国产软件常见的"暗桩"位置都包了：

| 扫描位置 | 典型表现 |
|---|---|
| 资源管理器右键菜单 | 文件右键出现一堆无关的"上传 / 转换 / 打开方式" |
| "此电脑"网盘图标 | 已卸载的网盘还在导航栏占位置 |
| 开机启动项 / 启动文件夹 | 开机莫名其妙慢 30 秒 |
| Windows 计划任务 | 后台定时拉起推广、弹窗、守护进程 |
| Windows 后台服务 | 已卸载软件残留服务在后台跑 |
| 浏览器外部宿主 / 扩展策略 | 被强行装上的插件、被改的主页 |
| 文件关联 / 打开方式 | 默认打开方式被悄悄换掉 |

匹配方向包括：360 系列、WPS/金山、百度系、夸克系、搜狗、迅雷、钉钉、腾讯系、2345、Bandizip 系，以及常见国产压缩、看图、影音、驱动、管家、PDF/办公捆绑工具的残留。

## 05 · 边界

这个工具的原则，作者写得很直白：**宁愿少删，也不乱删。**

它不会做的事：默认卸载主程序、删除用户文档、改写 UserChoice、强行绕过自保护、联网上传数据、常驻后台。

它会做的事：清理前先备份、清理后复核、失败时留在复扫列表、原生 C# WinForms EXE、不加壳不混淆、不内嵌脚本。

> ⚠️ 关于安全软件误报：这个工具会读取、备份、删除注册表项，禁用服务和计划任务，被 360 / 火绒 / Defender 归到"系统清理/潜在风险工具"不奇怪。建议下载后核对文件名和 SHA256，介意的直接下源码自行审查编译。

## 06 · 上手

1. 从 GitHub Release 下载单文件 EXE，核对文件名和 SHA256
2. 双击运行，点"开始抓现行"（涉及 HKLM/服务/计划任务，建议用"管理员模式"打开）
3. 看清楚每一项，自己勾选要清理的——"在哪里冒出来 / 用户看到什么 / 怎么处理"，每条都标得明明白白

## ∞ · 闲话

说真的，"被安排"这事最让人难受的不是不能卸载，而是你根本不知道它在你电脑里悄悄做了什么。

RogueCleaner 让我喜欢的一点是：它先把真相摆在你面前，再让你自己决定清不清——而不是替你一键解决。

如果你电脑右键菜单已经被国产软件塞满，今晚扫一次，估计能多腾出半屏。
