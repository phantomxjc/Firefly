# 飞牛NAS上藏了一个游戏厅？手把手教你搭建私人H5游戏平台

周末在家里翻出个手柄，突然就怀旧了。想起小时候偷偷在电脑课上打2048、课间跟同桌下五子棋的日子，那时候的快乐好像特别简单。

后来我在飞牛NAS的应用中心闲逛，发现了一个叫"轻游戏"的应用。装上一看嚯——这不就是一个私人H5游戏厅吗？手机、电脑打开网页就能玩，不需要装任何客户端，也不需要模拟器 ROM 折腾。

今天就分享一下怎么在飞牛上把它跑起来，以及怎么往里头添加游戏。

## 这玩意儿到底是什么

轻游戏是飞牛NAS应用中心里的一款原生应用，一键安装，装完就能用。本质上是一个自托管的H5游戏管理平台，支持按分类管理游戏、添加封面、设置横竖屏，还能导入模拟器游戏。

说人话就是：你自己的NAS上跑一个游戏网站，局域网里谁打开就能玩，外网也能通过内网穿透访问。没有广告，没有注册，没有氪金弹窗。

目前版本1.0.5，界面挺干净的，支持多用户、游戏分类、存档管理这些功能。

## 三步完成部署

### 01 安装应用

打开飞牛NAS的网页管理界面，进入应用中心，搜索"轻游戏"，点击安装就行。不需要手动配Docker、不需要敲命令行，全程鼠标点点点。

装完之后系统会自动分配一个端口（默认8666），应用就跑起来了。

### 02 登录管理后台

浏览器打开 `你的NAS_IP:8666`，默认管理员账号是 `admin`，密码 `admin123`。

第一次登录建议改一下密码。进后台之后你会看到一个比较简洁的管理界面，左边是游戏列表，右边可以分类管理、用户管理、系统设置。

### 03 创建游戏分类

在管理后台的分类管理里，可以先建好你想要的分类。比如我建了这些：

- 休闲益智（贪吃蛇、2048、俄罗斯方块、扫雷、井字棋）
- 益智解谜（记忆翻牌）
- 街机经典（打砖块）
- 射击竞技（太空射击）
- 跑酷敏捷（Flappy Bird）
- 棋牌桌游（五子棋）

分类建好之后，接下来就是往里头添游戏了。

## 怎么添加游戏

这是整个过程中最有意思的部分，也是容易踩坑的地方。

轻游戏添加H5游戏的方式是 **ZIP包导入**，不是填URL链接。踩过这个坑——刚开始我以为跟其他游戏平台一样直接贴一个网页地址就行，结果发现游戏根本启动不了，报"游戏文件不存在"。

ZIP包的正确结构是这样的：

```
game.zip
├── config.json        # 游戏配置文件
└── game_files/
    └── index.html     # 游戏主文件
```

### config.json 长什么样

```json
{
  "name": "贪吃蛇",
  "cover_path": "",
  "category_id": 1,
  "sort_order": 0,
  "is_hidden": 0,
  "is_landscape": 0,
  "tag": "default",
  "game_type": "H5"
}
```

几个关键字段的含义：

- **name**：游戏名称，会显示在前台列表里
- **category_id**：分类ID，对应你在后台建的分类序号
- **is_landscape**：是否横屏。1=横屏（适合打砖块这类），0=竖屏（适合贪吃蛇这类）
- **game_type**：游戏类型，H5游戏就填"H5"
- **cover_path**：封面图URL，留空的话前台会显示默认图标

### 怎么打包导入

写好或者找一个H5游戏的index.html文件，跟config.json一起放进一个目录里，目录结构就是 `config.json` 在根目录，`index.html` 放在 `game_files/` 子目录下。

然后用zip工具压缩整目录，在管理后台点"导入游戏"，上传这个zip包就行。系统会自动读取config.json、解压游戏文件到本地存储、注册到数据库，整个过程两三秒。

导入完成后游戏就出现在列表里了，前台马上就能玩。

### 小技巧

- 如果游戏是网上找的开源H5项目（比如GitHub Pages上的那种），把整个项目下载下来，改成 `game_files/index.html` 的结构打包就行。前提是那个项目没有 `X-Frame-Options: SAMEORIGIN` 的限制，否则iframe加载不了。
- 封面图建议用480×270的URL链接，不想找图的话留空也行，但有了封面前台会好看很多。
- 横屏游戏（打砖块、太空射击）记得把 `is_landscape` 设为1，手机上会自动转横屏。
- 每次修改游戏信息后，记得把name字段也一起带上，不然可能被清空。这是当前版本一个小坑。

## 实际体验

装完之后在手机上打开 `NAS_IP:8666`，上手体验还不错。页面加载很快，因为是局域网直连，几乎没有延迟。贪吃蛇滑动操作灵敏，2048滑动也有动画，Flappy Bird点击跳跃响应正常。

唯一的小问题是有些游戏的触屏适配还需要优化一下，比如太空射击在手机上操作稍显别扭，还是电脑上用键盘玩更爽。

另外一个比较实用的点是：支持多用户。家人可以各自注册账号，各自记各自的最高分。虽然目前的排行榜功能还比较简单，但基本够用了。

## 适合什么人

如果你有飞牛NAS，偶尔想玩两把小游戏放松一下，又不想在手机上装一堆广告满天飞的游戏APP，轻游戏确实挺合适。

不需要折腾Docker命令、不需要懂代码、应用中心一键装、游戏ZIP包导入即玩。整个搭建过程大概十分钟，其中八分钟在建分类和找游戏素材。
