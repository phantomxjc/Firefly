## 01 · 前言：为什么折腾自动签到？

WorkBuddy 的每日签到积分虽然不多，但**30 天不领就清零**。

最尴尬的是——这玩意儿没有"补签"功能，错过就是错过了。

我之前就是想起来才点一下，想不起来就丢了。后来攒够经验才发现：**青龙面板 + 一个 Python 脚本 = 每天 7:30 自动签到**，彻底解放双手。

这篇教程把整个部署过程拆成 3 大步，每一步都给你看清楚要做什么。**跟着点，绝对不会出错**。

整个部署完成后，你每天起床就能看到积分到账，睡懒觉也不怕。

## 02 · 准备：先搞清楚你有什么

在开始之前，先确认你手上有这些东西：

| 项目 | 怎么确认 |
|---|---|
| 一台跑青龙的服务器（NAS/小主机都行） | 浏览器能访问 `http://你的IP:5700` |
| WorkBuddy 客户端已登录 | 电脑/手机上能正常用 |
| 青龙面板的账号密码 | 默认 `phantomxjc / ***`（不知道就去查）|

### ⚠️ 不知道青龙密码怎么办？

去服务器终端跑：
```bash
docker exec qinglong sqlite3 /ql/data/db/database.sqlite \
  "UPDATE Auths SET info=json_set(info, '$.password', '新密码') WHERE id=3"
```

改完用新密码登录。

## 03 · 第 1 步：拿 token 和 uid（5 分钟）

> 这一步在你**已经登录 WorkBuddy 的那台电脑**操作

### 🪟 Windows 用户

1. 打开 WorkBuddy 客户端，确保已登录
2. 按键盘 `Win + R`（调出运行框）
3. 输入下面这串字符，回车：
   ```
   %LOCALAPPDATA%\CodeBuddyExtension\Data\Public\auth
   ```
4. 弹出的文件夹里找 `workbuddy-desktop.info`
5. **右键 → 打开方式 → 记事本**
6. 看到一段 JSON，**完整复制**两个值：
   - `auth.accessToken`（一长串 `eyJ...` 开头）
   - `account.uid`（UUID 格式）

### 🍎 macOS 用户

打开终端（`Cmd + 空格` 搜 Terminal），运行：
```bash
cat ~/Library/Application\ Support/CodeBuddyExtension/Data/Public/auth/workbuddy-desktop.info
```

### 🐧 Linux 用户

```bash
cat ~/.config/CodeBuddyExtension/Data/Public/auth/workbuddy-desktop.info
```

### ✅ 检查清单

```
□ accessToken 完整复制（eyJ 开头很长一串）
□ uid 完整复制（UUID 格式）
```

## 04 · 第 2 步：青龙面板加环境变量（3 分钟）

### 2.1 登录青龙面板

浏览器打开 `http://你的青龙IP:5700`，登录。

### 2.2 进入环境变量页面

顶部菜单 → 点 **「环境变量」** → 点 **「新建变量」** 或 **「+」**

### 2.3 填写变量

| 字段 | 填什么 |
|---|---|
| **名称** | `WORKBUDDY`（**大写，一字不差**）|
| **值** | `<accessToken>#<uid>#主账号` |
| **备注** | 随便写，比如 `WorkBuddy自动签到` |

**值的格式**是三个 `#` 分隔四部分：**token + uid + 备注**。中间不能有空格。

举个例子：
```
eyJhbGciOiJSUzI1NiIsInR5cCIgOi...#f0dc37d7-3646-4f0e-98aa-aa3b5bc484d2#主账号
```

点 **「保存」** ✅

---

## 05 · 第 3 步：脚本 + 定时任务（10 分钟）

### 3.1 上传签到脚本

1. 顶部菜单 → **「文件管理」** 或 **「脚本管理」**
2. 进入 `scripts` 文件夹
3. 把 `workbuddycheckin.py` 脚本**上传**到这里
4. （脚本内容找文末索取）

### 3.2 新建定时任务

1. 顶部菜单 → **「定时任务」** → 点 **「新建任务」**
2. 按下面填：

| 字段 | 填什么 |
|---|---|
| **名称** | `workbuddy自动签到` |
| **命令** | `python3 workbuddycheckin.py` |
| **定时规则** | `30 7 * * *`（每天 7:30）|
| **状态** | ✅ 启用 |

3. 点保存

### 3.3 立即测试

1. 在定时任务列表找到 `workbuddy自动签到`
2. 点右边的 **「运行」** 按钮（或 ▶️ 图标）
3. 等几秒，看日志

**成功的日志长这样：**
```
INFO 共加载 1 个账号, 开始签到
INFO 账号[主账号] 已加载登录态
INFO 账号[主账号] 签到前总积分: 4200
INFO 账号[主账号] ✅ 签到成功 (连续 1 天)
INFO 签到后总积分: 4300
```

### ⚠️ 失败怎么办？

| 报错 | 原因 | 怎么修 |
|---|---|---|
| `未找到任何登录态` | WORKBUDDY 没填对 | 回去检查第 2 步 |
| `HTTP 401` | token 过期了 | 重新走第 1 步 |
| `HTTP 404` | API 路径变了 | 等官方修复或换 API |

## 06 · 进阶：加第二个账号

想管多个账号？很简单。

### 拿新账号的 token

1. 在**另一台电脑**（或虚拟机）登录 WorkBuddy 的第二个账号
2. 走一遍第 1 步，拿到新 token + uid

> **注意**：同一台电脑同时只能登一个账号。

### 更新 WORKBUDDY 变量

回到第 2 步，编辑 WORKBUDDY，把值改成两行（**换行分隔**）：

```
<第一个token>#<第一个uid>#主账号
<第二个token>#<第二个uid>#小号
```

走一遍第 3 步测试，应该看到两个账号都签到成功。

## 07 · 日常维护：每 60 天换一次 token

token 大约 60 天过期。过期后脚本会报 401。

### 怎么发现 token 过期？

定时任务跑完后，日志出现 `HTTP 401` 或 `令牌失效`。

### 怎么换？

1. 在 WorkBuddy 客户端**登出再登录**（刷新 token）
2. 重新走**第 1 步**拿新 token
3. 重新走**第 2 步**更新 WORKBUDDY
4. 走**第 3.3 步**重新测试

### 💡 懒人技巧

每 50 天手动跑一次测试，能提前发现 token 快过期。

## 08 · 常见问题

### Q1：青龙密码忘了怎么办？

```bash
docker exec qinglong sqlite3 /ql/data/db/database.sqlite \
  "UPDATE Auths SET info=json_set(info, '$.password', '新密码') WHERE id=3"
```

### Q2：能改成每天跑两次吗？

把定时规则改成 `30 7,19 * * *`（7:30 和 19:30 各一次）。

### Q3：脚本跑了但没通知我？

签到本身没问题，只是没配微信通知。要推送的话需要配 WxPusher 或企业微信机器人（**本文档不展开**）。

### Q4：跑失败会重试吗？

**不会**。青龙只负责按点跑，失败了就失败了。

### Q5：积分能干嘛？

WorkBuddy 里用 Hy3 模型要积分。30 天过期，及时用掉。
