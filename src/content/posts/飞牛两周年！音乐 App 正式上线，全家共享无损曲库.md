## 二、飞牛音乐 v1.0.0：NAS 上的"正版 Apple Music"

这次更新最大的主角其实是**飞牛音乐**——一个原生集成在飞牛 OS 里的音乐服务。我之前一直用 LX Music + ro 容器自己搭，能用是能用，但每次新设备都要重新配置音源脚本，体验有点割裂。

飞牛音乐走的路子不一样——**它直接接管 NAS 里的音乐文件夹**，然后给手机、平板、电脑都提供客户端：

- 📱 **iOS / 鸿蒙 / 安卓 App**（v1.35.2 起支持，iOS 和鸿蒙已提审）
- 💻 **Web 端**（飞牛 OS 系统应用，浏览器直接访问）
- 🎵 **高音质播放**（DSD、DTS、无损、整轨 CUE 识别）

最戳我的几个点：

**1. 自动刮削**

丢一个音乐文件夹进去，飞牛音乐会**自动按专辑、歌手归类**，自动拉歌词、自动下载封面。以前用 LX + ro 的朋友知道，光是给一两千首歌重命名 + 嵌入封面就能折腾一下午，飞牛音乐直接把这一步省了。

**2. 多端同步 + 全家共享**

家里每个人一个独立的飞牛音乐账号，可以登录同一台 NAS。**收藏、最近播放、歌单**这些数据是按账号分的——娃听儿歌、你听摇滚、爸妈听红歌，互不干扰，但曲库是同一份。

**3. 离线缓存 + 音质切换**

手机上可以选**自动缓存 / 手动下载**，还能**按网络环境切换音质**（WiFi 下无损、流量下 320k）。我之前用 LX 移动版出门就得提前下好歌，现在直接缓存完丢在那里，啥时候想听都行。

**4. DSD / DTS 这种高规格音频**

这一点真的意外——飞牛音乐居然原生支持 **DSD、DTS 等大量高音质音频格式的无损播放**，还能识别整轨 CUE 文件。

手里有一堆老 DTS-CD、DSD 资源的朋友这次可以放心了，不用再单独找 foobar2000 之类的播放器。

## 三、飞牛 APP v1.35.2：把音乐彻底搬到口袋里

和飞牛音乐同时更新的还有飞牛客户端 v1.35.2，**移动 App 终于内置了音乐模块**。我看了下 changelog，关键功能：

| 功能 | 说明 |
|---|---|
| 高音质播放 | DSD、DTS、无损全格式支持，整轨 CUE 自动识别 |
| 自动缓存 | 按网络环境选音质，本地下载管理 |
| LRC 歌词 | 歌词查看 + 偏移调整 + 锁屏控制 |
| 系统中断恢复 | 切后台、来电打断后自动续播 |
| 智能筛选 | 按专辑、歌手、风格筛选和搜索 |
| 全曲库漫游 | 随机播放整库，管理收藏 / 最近播放 / 歌单 |
| 信息编辑 | 手动编辑歌曲元数据，刮削错了可以改 |
| 多人多端 | 管理员可扫描文件夹、多用户隔离 |

iOS 和鸿蒙版目前还在提审，安卓应该已经能更新了。具体可以进飞牛公众号看完整 changelog：

更新日志：https://mp.weixin.qq.com/s/-IDJcMuEkepGiSSQhd7svw

## 四、动手党关心的事

我自己没第一时间上，因为**家里囤的几千首歌之前都散在 ro 的下载目录里**。这次要做的迁移工作：

1. 把 `/vol3/1000/影音/NAS下载音乐/` 里的文件复制到飞牛音乐指定的音乐库目录
2. 进飞牛音乐管理后台，**扫描音乐文件夹**
3. 等它刮削完，**检查一遍封面和歌词**（自动刮削正确率大概 90% 出头，少数需要手动补）
4. 手机 App 登录后，**勾选要同步的播放列表**

整个过程预计半天到一天，主要看曲库大小。

如果你之前没怎么折腾过飞牛音乐，**官方给了三个介绍视频**，可以先看看：
